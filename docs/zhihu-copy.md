# 一键复制到知乎专栏（2026-07-30 起）

公众号排版预览那排按钮里的「知乎专栏」：**纯前端确定性转换**，点了即刻写剪贴板，
不碰 AI、不碰接口（跟「复制到公众号」同性质，跟小红书那条要先跑 AI 高亮的链路不同）。

渲染器：`lib/zhihu-article.ts`（注意与 `lib/zhihu.ts` 区分——那份是知乎开放平台**采集**客户端，跟发文无关）。

## 为什么又是独立一套 HTML
公众号那份满是 `<section style>` 的 HTML 不能直接用：富文本编辑器对认不出的块级容器，
要么把内联样式剥光、要么把内部结构压塌成一个大段落（X Articles 就是后者，见 [twitter-copy.md](twitter-copy.md)）。
所以顶层必须是**裸语义化标签**。

## 与推特长篇那份的两条关键差异
| | 知乎 | X Articles |
| --- | --- | --- |
| 图片 | **保留 `<img>`**：知乎粘贴会自动抓取转存（与公众号同机制） | 粘不进去，原位换成「📷 配图N」提示行 |
| 代码块 / 分隔线 / 表格 | 有对应块型，`<pre><code>` / `<hr>` / `<table>` 原样保留 | 没有块型，一律拍平成段落 |

## 转换规则
- **标题**：`##` → `<h2>`（知乎一级标题），`###` 及以下 → `<h3>`（二级标题）。知乎只有两级标题，`<h1>` 会被降级，索性从 h2 起用
- **行内**：`strong` / `em` / `del` / `code` / `a[href]` 保留；`mark` / `u` / `sup` / `sub` / `span` 等脱标签保文字
- **块级容器**：`figure` / `section` / `div` 等一律脱掉（留一个就有压塌结构的风险），脱完裸在 body 下的 `img` 补一层 `<p>` 保证独立成段
- **图注**：`figcaption` → 独立 `<p>`（在脱容器之前做，否则会被并进图片段落）
- **属性**：只留 `a[href]` 与 `img[src|alt]`，内联样式 / class / data-* 全清
- **节奏对齐**：复用 `reflowProse` 的「每段 1~2 句」，跟公众号预览同一个呼吸感（内联样式带不过去，能对齐的只有结构与节奏）
- **纯文本兜底**（`text/plain`）：不含任何 markdown 记号的排好版文本；列表 → `· ` / `1. `，引用 → `「…」`，分隔线 → `· · ·`，表格 → `单元格 ｜ 单元格`，图片段落 → `（配图）`
