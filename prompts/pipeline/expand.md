# 素材 → 稿件 四阶段流程

铁律先行：**素材是起点，不是成品。** 任何一条素材（一则行业新闻、一个知识点、一段观察）都不允许原样搬运、平铺转述或简单翻译。必须走完下面四阶段，产出的东西要能看出是"某个具体的人，带着某个具体视角，对这条素材做了消化和再创造"。

素材有两类，处理路径不同：

- **外部资讯类**：RSS 抓来的新闻/热点。天然是别人已经报过的，价值不在转述，在于交叉视角的评判和增量信息。
- **自积累素材**：用户自己录入的知识点、观察、灵感。价值在深化和补最新证据。

---

## ① 选题：素材 → 一句话 angle（+ 可选人设）

- 读完素材，先想清楚要用什么视角切入（若选题带了 persona 人设补充，以它为视角基准），再写出**一句话切入角度**：不是"这条素材讲了什么"，而是"我要从什么角度、对谁、说一个什么主张"。
- angle 必须有立场或有信息增量。反例："OpenAI 发布了新模型。" 正例："新模型把上下文拉到 100 万 token，但长文档检索仍会漏中段——这事对做 RAG 的人意味着什么。"
- **外部资讯类硬性要求**：绝不平铺转述"发生了什么"。必须给出有信息增量的评判视角——它靠不靠谱、对目标读者意味着什么、和已有认知哪里冲突。没有视角的新闻转述，直接毙掉重选。
- 输出：`angle`（一句话）+ `persona`（可选的人设/视角描述）。

## ② 回溯与调研：把 angle 坐实

这一阶段的产物统一写入 `research` 字段，供下一阶段引用。

- **外部资讯类**：**强制回溯 url 抓第一手原文**（原始博客、论文、发布公告、原推），不能只信二手报道。提炼关键要点，**逐条记出处**（机构 + 日期 + 链接）。二手转述里的数字和结论要回原文核对。
- **自积累素材**：主动**补最新研究、数据、案例**。科学类要找得住的真研究（作者/机构/年份/结论），不能"研究表明"糊弄；技术类要找版本号、benchmark、真实工具行为。
- 调研结果按此结构存入 `research`：关键数据（带出处）、可引用的原话（带说话人）、案例/故事、反面观点/争议。
- 底线：宁可少写一个论据，也不留一个查不到出处的"研究表明"。参见 anti-ai-rules 的模糊归因禁令。

## ③ 扩写母稿：要点 + 调研 + 素材 + 视角 → 有血有肉的母稿

母稿是平台无关的"完整思考版"，是后续所有平台变体的母版。必须齐备三样东西：

- **观点**：明确的主张和态度，不中立报道（见 anti-ai-rules 个性与灵魂）。
- **案例/证据**：来自 `research` 的具体数据、原话、故事，全部带出处。
- **个人视角钩子**：第一人称的经历、感受或反直觉判断。"我踩过的坑""让我意外的是""我一开始以为……结果……"。这是把知识点变成"你的稿子"的关键。

母稿写作全程遵守 anti-ai-rules，节奏长短交错、有观点、承认复杂性。

## ④ 平台变体：母稿 → 各平台派生

- 按目标平台的规范文件（platforms/ 下）从母稿派生变体，不是复制粘贴，而是按平台读者、体裁、长度重新组织。
- 各平台硬约束以 platforms/ 下对应文件为准（字数、结构、标签、参考来源等）。
- **每一篇变体产出后，逐条对照 `anti-ai-rules.md` 自查，不过就地重写。** 这是发布前最后一道闸。

---

流程小结：`素材 → (①angle+persona) → (②research) → (③母稿) → (④平台变体 + 自查)`。任何一步偷懒直接搬运，都算不合格。
