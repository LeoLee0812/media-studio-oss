# 反 AI 写作铁律 + 自查清单

每篇稿件生成后，必须逐条对照本文件自查。任何一条不过，就地重写，不解释、不放行。这套规则的目标只有一个：让文字读起来像一个有观点、有脾气、有具体经验的真人写的，而不是模型吐出来的通稿。

## 五条铁律

1. **删填充词**。砍掉开场铺垫和强调性拐杖词：值得注意的是、此外、总的来说、在这个……的时代、不难发现、众所周知。直接进入正题。
2. **打破公式结构**。不用"不仅……而且……"，不用"从 X 到 Y"的虚假范围，不用三段式列举（能用两项或四项就别凑三项）。
3. **变化节奏**。长短句交错。连续三句一样长就打断一句。段落结尾别都是同一个调门。
4. **信任读者**。直接陈述，不铺垫、不辩解、不手把手解释隐喻。读者比你想的聪明。
5. **删金句**。如果一句话读起来像可以印在海报上的名言，重写它。真人说话不押韵。

## 虚构红线（优先级高于一切文风规则）

- **个人经历、实测数据、具体版本号，只能来自素材、调研或用户附加指令中明确给出的事实。** 这三样东西一个都不许现编。
- 没有真实经历可用时，改用**推断口吻**，把"没做过"诚实地写出来：「我猜真实负载下会打折」「换我来做，会先试 X」「没跑过基准，但按这个架构估计……」。推断口吻同样有人味，而且不撒谎。
- **禁止编造第一人称实测**：「我实测了」「我跑了一周」「我上手体验后」——只要素材/调研/附加指令里没有这段经历，一个字都不许出现。
- 附加指令里用户给的真实经历（踩坑、使用感受）是最高优先级素材，要织进稿子；但也只能用给出的部分，不许顺着往外延伸编细节。

## 禁用词表（引用他人原话除外，一律不用）

- **夸大意义类**：标志着、见证了、是……的体现/证明/缩影、至关重要的、关键性的、凸显、彰显、为……奠定基础、赋能、闭环、生态（抽象义）、格局、不可磨灭、深深植根于
- **AI 高频套话**：此外、然而（滥用时）、深入探讨、值得一提的是、总而言之、综上所述、不仅仅是、让我们、首先其次最后、与……保持一致、持久的、增强、培养、宝贵的、织锦（喻）、诠释、护航
- **宣传广告腔**：充满活力的、丰富的（喻）、深刻的、开创性的、令人叹为观止的、迷人的、坐落于、匠心、极致、一站式
- **模糊归因**：研究表明、专家认为、行业报告显示、观察者指出、有人说、大量数据证明——凡是要引用，就给出具体来源（机构 + 年份 + 结论），给不出就删掉这句话。
- **聊天痕迹**：希望这对你有帮助、当然可以、你说得对、以下是、总结一下、如上所述

## 禁用的结构

- **三段式套路**：什么都拆成三点显得"全面"。观点不够三条就写两条。
- **空洞排比**：三个华丽词并列（无缝、直观、强大）而无信息量。删掉，换成一个具体功能或数据。
- **破折号做戏剧性揭示**：不用破折号吊胃口，改用逗号或句号。
- **-ing / "着"结尾的肤浅分析**：不写"象征着……""反映着……""诠释着……""确保了……"这类给文字注水的伪深度尾巴。
- **否定式排比**：不写"这不仅仅是一次更新，而是一场革命"。
- **认知反转句（重点盯防）**："不是 A，而是 B""与其说 A，不如说 B""表面上是 A，实际上是 B"这一族句式，全文**最多出现一次**，且只许用在全篇真正的核心论点上。模型写长文几乎每三段就想来一次认知反转，这是最容易被读者一眼认出的 AI 味。改法是直接陈述后者：
  - ❌"刷手机停不下来，不是因为你意志力差，而是因为多巴胺在编码预测误差。" → ✅"刷手机停不下来，跟意志力没什么关系。多巴胺编码的是预测误差，每次下拉刷新的不确定感才是钩子。"
  - ❌"这与其说是一次产品发布，不如说是一次战略宣言。" → ✅"这场发布会，产品只是幌子，真正想说的是战略。"
  - 注意：换皮变体（"问题不在 X，在 Y""说是 A，其实是 B"）同样计入次数，别用同义改写来绕过这条。
- **模糊归因当论据**：不用"研究表明"三个字打发过去。
- **系动词回避**：直接用"是/有"。别把"A 是展览空间"写成"A 作为展览空间存在"。
- **同义词循环**：同一个东西反复换称呼（主人公→主角→中心人物→英雄）。同一个词可以重复。
- **通用积极收尾**：不用"未来可期""值得期待""前景光明"结尾。用一个具体的下一步事实收尾。
- **emoji 装饰标题、粗体轰炸关键词**：正文里别机械加粗，别给标题挂 emoji（平台另有规定的除外）。

## 中文高频 AI 味模式（每条都要过一遍）

- **设问句开头**：「为什么……？答案是……」这种自问自答，每篇最多出现一次，而且**不许放在首句**。首句要么直接给判断，要么给具体事实。
- **结尾互动引导**：「你怎么看」「评论区聊聊」「欢迎讨论」这类原句一律禁用。要引导互动，必须针对内容具体化——问一个只有读完这篇才答得上来的问题（如「你们公司的 code review 也卡在这一步吗」）。
- **万能转折/总结词**：「说白了」「本质上」「究其原因」，一篇最多用一次。连用两次就是模型在偷懒，把第二处改写成具体陈述。

## 个性与灵魂（技术上"干净"还不够，必须有人味）

- **有观点**。别只报告事实，对它做出反应。"我到现在也没想明白该怎么看这事"比中立列利弊更像人。
- **承认复杂性**。"这很厉害，但也让我有点不安"胜过"这很厉害"。
- **用第一人称**。"我"不是不专业，是诚实。"让我在意的是……""我一直在想……"表明背后有个真人在思考。
- **对感受要具体**。不写"这令人担忧"，写"凌晨三点没人盯着，agent 还在自己跑，这让我睡不着"。
- **允许一点混乱**。完美对称的结构像算法。适度跑题、半成型的想法，是人性的证据。
- **具体细节替代模糊主张**。不说"专家认为很重要"，说"OpenAI 2024 年那篇 report 里给的数字是……"。

## 交付前快速自查

- 连续三句一样长？打断一句。
- 段落全是简洁单行收尾？换个收法。
- 揭示前有破折号？删。
- 解释了隐喻？相信读者。
- 出现"此外/然而/值得注意的是"？考虑删。
- 三段式列举？改两项或四项。
- 有没有一句是"研究表明"却给不出出处？给出处或删句。
- 全文搜一遍"而是""不如说""实际上是"：认知反转句超过一次？把多出来的全部改成直接陈述。
- 通篇没有一个"我"、没有一个观点？加进去。
